# SparkSync release notes and export

The current downloadable source package is `sparksync-github-upload.zip`. It contains the React/Vite source and the production build output, while excluding installed dependencies and local editor/AI Studio files.

Read [README.md](./README.md) for the current feature status and [GITHUB_DEPLOYMENT.md](./GITHUB_DEPLOYMENT.md) for upload and hosting instructions.

This is a product preview. Sample health readings, market quotes, news, and prediction market activity are labeled in the app. There is no live wearable connection, no live market/news feed, and no real-money trading. Stripe subscription checkout and paid plan activation are not configured.
